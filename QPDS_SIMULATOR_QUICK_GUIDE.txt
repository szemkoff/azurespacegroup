================================================================================
CREATE CUSTOM SIMULATION (3 minutes)
================================================================================

Create a file: test_qpds.py

---begin code---
from qpds_simulator import QPDSSimulator, SimulationScenario, Position, EnvironmentType

# Create simulator
sim = QPDSSimulator()

# Create YOUR scenario
trajectory = [
    Position(x=0, y=0, z=0),      # Start
    Position(x=100, y=50, z=-20),  # Underwater point 1
    Position(x=200, y=100, z=-40), # Underwater point 2
    Position(x=300, y=150, z=-60), # Underwater point 3
]

scenario = SimulationScenario(
    name="My Underwater Test",
    environment=EnvironmentType.UNDERWATER,
    true_trajectory=trajectory,
    initial_position=trajectory[0],
    sensor_noise_level=15.0,   # Higher noise underwater
    update_rate=10.0,           # 10 Hz
    duration=3.0                # 3 seconds
)

# Run
results = sim.run(scenario)

# See results
print(results.summary())
print(results.to_json())
---end code---

Run it:
  python3 test_qpds.py

================================================================================
SUPPORTED ENVIRONMENTS
================================================================================

- SURFACE:     Harbor, open air (GPS available for reference)
- UNDERWATER:  Ocean, lakes, submerged (15+ pT noise)
- UNDERGROUND: Tunnels, mining, caves (variable signature quality)
- TUNNEL:      Built tunnels, subways (good signature if surveyed)
- URBAN:       City environments (multiple signature sources)

================================================================================
KEY COMPONENTS & CLASSES
================================================================================

QuantumSensor
  └─ Simulates SQUID magnetometer/gradiometer
  └─ TRL 4-5: Lab-demonstrated, near-commercial
  └─ Realistic noise models

GeophysicalDatabase
  └─ Pre-mapped magnetic and gravity signatures
  └─ Synthetic realistic data or load your own
  └─ Nearest-neighbor lookup

KalmanFilter
  └─ Bayesian sensor fusion
  └─ Combines INS + quantum sensor measurements
  └─ Estimates position and uncertainty

QPDSSimulator
  └─ Main orchestrator
  └─ Runs scenarios, manages measurements
  └─ Outputs JSON results

Position
  └─ 3D coordinates (x, y, z) in meters
  └─ Can calculate distance to other positions

================================================================================
TYPICAL WORKFLOW
================================================================================

1. DEFINE: Create a SimulationScenario with your trajectory
2. CREATE: Instantiate QPDSSimulator
3. ADJUST: Tune sensor noise, environment parameters if needed
4. RUN:    sim.run(scenario)
5. ANALYZE: Check results.summary() for performance
6. ITERATE: Try different parameters, sensors, environments

================================================================================
REALISTIC PARAMETERS
================================================================================

Quantum Sensors:
  Magnetometer noise:  5-20 pT (picotesla)
  Gradiometer noise:   2-10 pT/m
  
INS Drift:
  Typical: 0.01 m/s per second (velocity creep)
  Good:    0.001 m/s per second
  Poor:    0.05 m/s per second

Update Rate:
  Typical: 10 Hz (100 ms per measurement)
  Options: 1 Hz to 100 Hz

Signature Quality:
  Surface harbor:  0.95 (very distinctive)
  Open water:      0.85 (good variations)
  Tunnel:          0.80 (depends on survey)
  Deep underground: 0.70 (harder to match)

================================================================================
ADVANCED TRICKS
================================================================================

Better Sensors:
  sim.magnetometer = QuantumSensor("magnetometer", noise_level=3.0)

Custom Database:
  sim.geo_database = GeophysicalDatabase(grid_size=1000, resolution=5.0)
  # Then populate with real survey data

Tuned Kalman Filter:
  sim.kalman_filter = KalmanFilter(process_noise=0.001, measurement_noise=5.0)

Multiple Runs:
  for noise_level in [5, 10, 15, 20]:
      sim.magnetometer.noise_level = noise_level
      results = sim.run(scenario)
      print(results.summary())

GETTING HELP
================================================================================

Error: ImportError: No module named 'numpy'
  → pip install numpy

Error: File not found
  → Make sure you're in the project root directory

Sensor noise too high?
  → Reduce noise_level parameter (5 = better than 20)

Position errors huge?
  → Check signature_quality (0.5 = harder environment)
  → Increase geophysical database resolution
